OpenStamper

A stamp-based terrain compositing tool for Unity 6. Layer procedural features onto existing heightmaps with blend modes, preset libraries, and live preview.

Tools > OpenStamper  (Ctrl+Alt+S)
Required Dependency: OpenHeightmap

OpenStamper requires the OpenHeightmap asset to be installed in your project.

OpenStamper uses OpenHeightmap's HeightmapData container, HeightmapExporter, and ExportFormat enum at both runtime and editor level. If the Assets/OpenHeightmap folder is not present, OpenStamper will fail to compile with errors like:

The type or namespace name 'HeightmapData' could not be found (are you missing a using directive or an assembly reference?)

Install OpenHeightmap first, then add OpenStamper on top.

Quick Start

  1. Install OpenHeightmap into your project first.
  2. Copy the Assets/OpenStamper folder into your project.
  3. Go to Tools > OpenStamper (or press Ctrl+Alt+S).
  4. Click Load Base to import a heightmap from file, or Load OpenHeightmap to grab the current heightmap directly from the OpenHeightmap window. RAW16 recommended for full 16-bit precision.
  5. Use the Stamps tab to add stamp layers (Crater, Mountain, Ridge, etc.).
  6. Adjust position, radius, blend mode, intensity and the stamp's own shape settings in the Layer tab. Each layer keeps its own settings, so two craters can differ.
  7. Click Apply All to composite the stack onto the heightmap.
  8. Click Apply to Terrain to push to a scene terrain, or Export to save as PNG, RAW16, or EXR.

Stamps keep the base terrain's heights: adding a stamp never rescales the rest of the map. Anything stamped above 1 or below 0 is clipped on export, unless Normalize Result (Export tab) is on, which stretches the final heights to fill 0–1. If the scene has no terrain, Apply to Terrain creates one using the New Terrain settings in the Export tab (with Auto Height on, the height is a percentage of the width, 40% by default, adjustable with Height (% of width); Load OpenHeightmap also copies OpenHeightmap's setting, so a preset's suggested height carries over), with its own TerrainData asset in Assets/OpenStamper Generated (kept outside the tool folder, so updating the tool never touches your terrains).

Recommended Workflow

For best results, use RAW16 format throughout the pipeline:

OpenHeightmap (generate) → Export RAW16 → OpenStamper (load .raw) → Apply stamps → Export RAW16 → Unity Terrain (Import Heightmap)

RAW16 and PNG both store 16-bit height precision (65,536 levels); EXR stores full 32-bit floats. RAW16 is the format Unity's terrain Import Raw reads directly. EXR import depends on your Unity version; use RAW16 if an EXR won't load.

Features

7 Procedural Stamps

Crater, Mountain, Ridge, Valley, Plateau, River, and Noise. Each with unique configurable parameters.

8 Blend Modes

Add, Subtract, Multiply, Max, Min, Average, Replace, and Power. Control how stamps interact with existing terrain.

Layer Stack

Stack unlimited stamps, reorder them, toggle individual layers, and preview single layers in isolation.

Live Preview

CPU-rendered colored heightmap preview with zoom and click-to-read height. Rendered once per change, so editing stays responsive.

Preset Libraries

4 built-in presets (Impact Site, Mountain Valley, River Cut, Mesa). Save and load custom libraries as ScriptableObjects.

Apply to Terrain

Push stamped heightmap directly to a terrain in the scene. Creates new terrain or updates existing with undo support.

Multi-Format Import & Export

Import square PNG, RAW16 (16-bit precision), or EXR (where Unity supports it). Export as PNG (16-bit), RAW16, or EXR. RAW16 recommended for full-precision pipelines.

Blend Modes

Each stamp layer has a blend mode that controls how it merges with existing terrain heights. Blending only happens inside the stamp's radius: the final height is lerp(terrain, result, coverage × intensity), where coverage fades from 1 at the center to 0 at the edge (shaped by Falloff Power). Intensity above 1 only adds extra strength for Add and Subtract.

ModeFormulaUse Case
Addresult = terrain + stampThe default for every stamp: raised shapes rise, carving shapes (Crater, Valley, River) dig in
Subtractresult = terrain - stampThe exact opposite of Add: a mountain becomes a pit, a crater becomes a mound
Multiplyresult = terrain * stampErosion overlay, terrain modulation
Maxresult = max(terrain, stamp)Peak sculpting, cliff capping
Minresult = min(terrain, stamp)Floor lowering, peak cutting
Averageresult = (terrain + stamp) / 2Smooth blending, terrain correction
Replaceresult = stampFull overwrite within stamp area
Powerresult = terrain ^ (1 - stamp)Contrast adjustment, sharpening

Workflow

OpenStamper works as a layer stack composited onto an existing heightmap.

Load Base Heightmap → Add Stamp Layers → Adjust Parameters → Apply Stack → Export

The stack processes top-to-bottom of the Layer list (the last layer is applied last). Each enabled layer is sampled directly at the heightmap's resolution, so stamps stay sharp, and blended according to its blend mode. Radius is the distance from the stamp's center to its edge, as a fraction of the terrain width. Preview This Layer shows one layer on the base without changing the result; click Back to Result to return. Loading a saved library works on a copy, so edits never change the saved asset until you save again. The base heightmap and stack survive script recompiles.

API Reference

IStampProvider
public interface IStampProvider
{
    string Name { get; }
    float Sample(float u, float v);  // normalized [0,1] UV space
}

All stamp types implement this interface. Returns height relative to the surrounding ground: 0 = no change, positive = raised (up to about 1), negative = carved below ground (Crater floor, Valley, River). With Add every stamp looks the way its name suggests. Invert flips the sign, so raised shapes become carved and carved shapes become raised.

StampLayer
var layer = new StampLayer("My Stamp");
layer.StampTypeIndex = 1;  // Mountain
layer.Position = new Vector2(0.5f, 0.5f);
layer.Radius = 0.15f;
layer.BlendMode = BlendMode.Add;
layer.Intensity = 0.8f;
layer.Mountain.PeakHeight = 0.9f;  // this layer's own Mountain settings

IStampProvider shape = layer.GetProvider();   // settings for the current StampTypeIndex
float[,] stampMap = layer.GenerateStampMap(shape, 257);

Defines a single stamp placement. Contains position, radius, rotation, blend mode, and its own copy of every stamp type's shape settings.

StampCompositor
var compositor = new StampCompositor();
compositor.Composite(heightmap, stack);

HeightmapData preview = compositor.PreviewSingle(heightmap, layer);
HeightmapData fullPreview = compositor.PreviewStack(heightmap, stack);

Blends the full stamp stack onto a HeightmapData. Each layer is sampled at the heightmap's resolution using its own settings and blended per its BlendMode, only inside its radius.

StampProviderRegistry
List<IStampProvider> stamps = StampProviderRegistry.Providers;
List<string> names = StampProviderRegistry.Names;
IStampProvider crater = StampProviderRegistry.GetProvider(0);

Registry of the 7 built-in stamp types: names, order (StampTypeIndex) and default settings. Each layer keeps its own settings copy; to add a stamp type, add it here and in StampLayer.

StampLibrary (ScriptableObject)
// Create via Assets > Create > OpenStamper > Stamp Library
var library = StampLibrary.Create("Assets/MyLibrary.asset");
library.Stack = myStack.Clone();  // save a copy, not a live reference

// Load a built-in preset
library.LoadPreset("Impact Site");

Persistent stamp stack configuration. Save/load stamp setups as project assets.
